# Yusuf Dash

Yusuf's own instrument-cluster themes ("Tachos") plus matching centre-screen dashes, all in one app. Needs
`cluster-render` (idrive-apps). Not for the HUD.

| Theme | Cluster | Centre screen (Dash tab) |
|---|---|---|
| Synthwave | neon sunset, grid that runs with the speed | vitals, sunset scene, G-radar |
| Lambo x BMW | carbon honeycomb, glass panels, wedge rev arc | same look, engine vitals + G-force |
| Chrom | three round chrome analogue dials | the same three dials |

The STIL button on the Dash tab cycles the three looks. New themes are generated by `tools/gen_*.py`.

Layer budget (cluster-render): at most 8 layers per connection and 16 MiB pixel memory for all apps together,
so keep the old Cluster Themes app off while this one runs.
